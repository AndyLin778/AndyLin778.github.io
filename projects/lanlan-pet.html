蓝蓝：双形态桌宠

普通形态和铁锅形态，来自拼豆图的像素造型。这里提供 Windows 独立桌宠与 Codex 宠物包两个版本。

Windows 独立桌宠

在 Windows 桌面上透明置顶运行。双击角色可切换形态；这个版本不读取 Codex 工作状态，运行时无需联网。

下载 Windows 桌宠 ZIP ↓

  1. 安装 Python 3，并确保 python 和 pythonw.exe 可在命令行使用。
  2. 解压 ZIP，在解压后的 lanlan-desktop-pet 文件夹打开 PowerShell，运行 python -m pip install -r requirements.txt 安装 Pillow。
  3. 双击 start-pet.vbs 启动。如果系统禁用了 VBS，在同一文件夹运行 pythonw .\pet.py。
  • 双击：切换普通 / 铁锅形态，并轻轻弹跳。
  • 按住左键：拖动桌宠。
  • 右键：跳跃、摇摆、开启散步、暂停、调整大小或退出。

退出时会记住形态、大小和位置。散步默认关闭，也不会设置开机启动。

Codex 宠物包

普通形态与铁锅形态是两个独立的 Codex v2 宠物选项，可在 Codex 宠物选择器中切换。

下载 Codex 宠物包 ZIP ↓

  1. 解压 ZIP，将 normal 文件夹里的 pet.json 和 spritesheet.webp 复制到 %USERPROFILE%\.codex\pets\lanlan-normal。
  2. 将 pot 文件夹里的同名两个文件复制到 %USERPROFILE%\.codex\pets\lanlan-pot。
  3. 重启 Codex，在宠物列表中选择想用的形态。

两套图集已通过 v2 结构与透明度检查。动画以弹跳、位移、眨眼和局部像素动作呈现。
