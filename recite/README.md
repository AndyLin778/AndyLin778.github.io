# 作文背诵

独立的纯静态背诵页。无需安装、构建、登录或联网。

## 打开

- 本机：双击本目录的 `index.html`。
- 网站：从主站顶部“作文背诵”进入，或访问 `/recite/index.html`（部署在子路径时加上对应前缀）。
- 独立使用：复制整个 `recite` 文件夹到其他位置，再打开其中的 `index.html`。不依赖主站的任何文件。

## 使用

选择范文后，英文默认展开，思路和中文默认收起。点击段落标题可单独收起或展开英文、译文；“全部收起 / 全部展开”只作用于英文，不改变中文和思路。切换篇目或刷新时恢复默认状态。键盘 Tab 可选择操作，Enter 或空格可切换折叠。

## 文件

- `index.html`：页面结构与入口。
- `style.css`：独立样式，支持手机布局。
- `app.js`：篇目切换、逐段折叠。
- `content.js`：生成后的范文内容，页面直接加载。
- `images/`：6 张大作文配图，全部为本地文件。
- `source/essays.md`：用户现有的《2021—2026 范文与思路（背诵版）》副本。
- `source/prompts.md`：用户现有的原题与配图说明副本（图片实际位于 `images/`）。
- `source/translations.json`：本页补充的中文翻译，每篇一个段落数组。
- `tools/build_content.py`：仅提取上述固定来源格式的内容脚本，不是通用 Markdown 渲染器。

每篇字段为 `id`（唯一标识）、`title`、`category`、`source`、`prompt`、`approach`（思路数组）与 `paragraphs`（段落数组）。每段包含 `en` 英文和 `zh` 中文。纯文本内容通过 textContent 显示；不解析 Markdown 或 HTML。换行可以写为 `\n`，长文本也可采用现有的反引号格式。

现有内容为 2021—2026 年，每年 Part A、Part B 各一篇，共 12 篇、56 组中英段落，按年份从新到旧排列。英文及思路沿用用户的背诵版材料，未改写；仅合并原文的排版换行、将书信称呼并入开场段，并移除思路表格的 Markdown 标记。中文为本页补译。通知标题、署名独立折叠，正文保留原分段。思路里的段落功能编号沿用源材料，其概括不一定与实际自然段编号逐一对应。

材料为背诵加长版，篇幅可能超过题目要求；源文件中的词数标注未经重新认定。来源的年份与真题归属沿用文件，未做外部核验；这些是参考范文，不是官方答案。6 张配图为资料站重绘/转录版，非官方扫描件。

修改 `source/essays.md` 或 `source/translations.json` 后，在项目根目录运行 `python recite/tools/build_content.py` 更新页面数据。脚本会检查 12 篇是否齐全、中英段落是否一一对应以及图片是否存在。日常打开页面不需要 Python。若直接修改 `content.js`，下次运行脚本会覆盖这些改动。

没有学习进度、计时、自动评分或云端功能。所有资源均在本目录，无外部字体、CDN、网络接口或主站资源依赖。

## 模块与精选内容（2026-10-27）

页面分为真题积累（12 篇）、预测卷（预测卷一 A/B 各一篇）和周测卷（待补充），共 14 篇、64 组中英对应内容、7 张配图。按题型或题材的分类暂不实现。

预测卷选入第九节 Repair Café 完整邀请邮件、第五节“磨刀不误砍柴工”打磨版。每篇附 6 条精选句架或词块，优先保留可迁移的表达和具体用法，排除重复版本、纯客套、可疑归属的名人名言及夸大的评分断言。源文保存在 `source/prediction01.md`，精选配置与翻译在 `source/prediction-selection.json`。大作文题面使用明确标注的题意概括，不冒充 Directions 原文。

小作文使用 `core` 标记区分核心与常显文字：称呼、纯客套、落款和通知标题不折叠；包含实际任务信息的开头、报名方式及邀约仍可折叠。`prefix` 用于将称呼从包含核心信息的开场段分出。点击“收起核心”只隐藏核心内容，常显文字保留在原位置；大作文继续逐段折叠。译文仍按部分独立展开。以上替代前文“所有英文段落均折叠”的说明。

重新生成仍使用 `python recite/tools/build_content.py`。脚本先校验 12 篇真题，再加入预测卷并校验 14 篇总量。新增模块可在 `app.js` 的 modules 配置中添加，内容使用 module 字段归属。
